# Font licences

The screen fonts (Settings → Screen font, 3.6) are bitmap versions of free fonts, made by `tools/make_screen_fonts.py`. Under the SIL Open Font License a converted font may not use a Reserved Font Name, so the firmware and the app describe each one by its style.

| Firmware font | App label | Made from | Licence |
|---|---|---|---|
| `FontHyperlegible13.h`, `FontHyperlegible12.h` | Hyperlegible | Atkinson Hyperlegible Bold (Braille Institute of America) | [OFL-Hyperlegible.txt](OFL-Hyperlegible.txt) |
| `FontPlainSans14.h`, `FontPlainSans13.h` | Plain sans | PT Sans Bold (ParaType) | [OFL-PlainSans.txt](OFL-PlainSans.txt) |
| `FontTerminal20.h`, `FontTerminal16.h` | Terminal bold | Terminus Font Bold, `ter-u20b` / `ter-u16b` | [OFL-Terminal.txt](OFL-Terminal.txt) |
| `FontSchoolbook14.h`, `FontSchoolbook10.h` | Schoolbook bold | Adobe New Century Schoolbook Bold X11 pixel font | Adobe/DEC permission notice, in each file |
