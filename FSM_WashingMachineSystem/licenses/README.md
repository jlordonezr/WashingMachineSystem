# Font licences

The optional screen fonts (Settings → Screen font) are bitmap versions of free fonts, made by `tools/make_screen_fonts.py`. Under the SIL Open Font License a converted font may not use a Reserved Font Name, so the firmware and the app describe each one by its style.

| Firmware font | App label | Made from | Licence |
|---|---|---|---|
| `FontHelvBold14.h`, `FontHelvBold12.h` | Original (Helvetica Bold) | Adobe Helvetica Bold X11 pixel font | Adobe/DEC permission notice, in the file |
| `FontNarrowBold13.h` | Narrow bold | Fira Sans Condensed Bold | [OFL-NarrowBold13.txt](OFL-NarrowBold13.txt) |
| `FontNarrowLight13.h` | Narrow light | PT Sans Narrow Bold | [OFL-NarrowLight13.txt](OFL-NarrowLight13.txt) |
| `FontSemiNarrow13.h` | Semi-narrow | Barlow Semi Condensed Bold | [OFL-SemiNarrow13.txt](OFL-SemiNarrow13.txt) |
| `FontRound13.h` | Round | Lato Bold | [OFL-Round13.txt](OFL-Round13.txt) |
| `FontSerifBold13.h` | Classic serif | Adobe Times Bold X11 pixel font | Adobe/DEC permission notice, in the file |
